# Amigo Secreto

Aqui podemos realizar um sorteio de amigos, onde todos podem levar um presente, ou algo combinados entre os participantes, e conforme cada um é sorteado pode escolher um presente, ou podemos chamar também de presente secreto. 

Conforme o amigo for sorteado o seu nome vai se apagando do sorteio automaticamente.

Espero que possam se diverte e usarem para realizar sorteios dos seus amigos.
